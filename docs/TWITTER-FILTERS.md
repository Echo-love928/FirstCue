# Twitter 热点筛选优化

2026-10-19 更新：按用户提高数量与效率的要求，当前门槛调整为点赞 ≥5、转发 ≥1、浏览 ≥200、作者粉丝 ≥50。其余原创类型、指标完整性、时效和相关性核验继续执行。下一轮正常采集或“重新核实”会重新分类已保存的候选，恢复因旧门槛过滤、如今达标的审核资格，无需重新搜索。下文保留 10 月 16 日实施及验证历史，其中旧数值已由此次调整替代。

> 后续多平台改造保留本文件全部 Twitter 规则；网页、B站、微博独立发现及 70% / 30% 分配见 [MULTIPLATFORM.md](MULTIPLATFORM.md)。

2026-10-16，用户逐项确认后实施。仅调整 Twitter 筛选与指标回查，其他来源、5 天窗口、AI 事实核验、通知和现有调用上限延续。

## 用户确认的规则

| 条件 | 要求 |
| --- | --- |
| 点赞 | ≥10 |
| 转发 | ≥5 |
| 浏览 | ≥500 |
| 作者粉丝 | ≥100 |
| 推文类型 | 仅纯原创；回复（含官方与原作者）、引用、纯转发全部排除 |
| 官方账号 | 同样满足全部四项门槛，无豁免 |
| 蓝 V | 同一时效档内，现有热度排序分 ×1.1，不更改官方身份或事实核验状态 |
| 缺失或未达标 | 先隐藏，5 天内补齐或增长达标后可重新审核入选 |
| 回查 | 随现有每 30 分钟检查执行，共用原 X 每日请求与结果预算；预算用尽等待后续处理 |

以上数值条件为 AND。零与缺失分别保存，缺失、负数、非整数或非有限数字均不放行。硬门槛通过后仍要经过既有内容价值、新颖性与事实核验，热度不等于事实成立。

## 实现

`shared/twitter.ts` 集中定义门槛、蓝 V 权重和资格判断。`quality.ts` 在候选选择前应用硬门槛；`sources.ts` 从同一 API 响应保存粉丝数、蓝 V 与指标检查时间。普通搜索、账号时间线与批量回查共用标准化逻辑。账号时间线关闭回复采集，后端仍再次校验类型。

回查每轮最多 50 条，按上次回查时间轮转，同一条 30 分钟内不重复回查。首次补齐时优先同轮已达到三项互动指标的内容；不依靠增量搜索重新碰到旧帖。响应按推文 ID 匹配，空 ID、缺失或不可读取项先隐藏；失败保留原始记录和下次回查资格。只回查 5 天内的纯原创，过期、回复和引用不耗费回查请求。

正文哈希未变但指标达标时，恢复候选审核资格；重复收到已达标数据不会重置现有 AI 重试次数。事件内嵌证据同步更新，避免候选和首页使用不同计数。旧版 Twitter 事件先隐藏，符合新门槛的推文重新经过 AI 审核；独立官方 RSS 事件不受影响。新审核结果不沿用被过滤的旧 X 证据。

普通“重新核实”继续仅使用本地材料，不新增采集网络请求；指标回查随常规或手动采集检查执行。暂停全部监控时不自行触发定时采集。

迁移保留所有原始数据，另存 `twitter-filter-audit-v1` 与 `twitter-event-audit-v1`。备份：`reports/backups/before-twitter-thresholds-2026-10-16.sqlite`。

## 验证

- 64 项自动测试通过；生产构建与差异检查通过。覆盖全部阈值边界、无官方豁免、引用/回复排除、10% 权重、指标恢复、批量 ID 匹配、30 分钟间隔、过期退出和现有预算限制。
- 真实批量回查 50 条，消耗 1 次 X 请求及 50 条结果额度；6 条符合候选筛选条件，AI 审核后保留 1 条待核实热点。其余继续按规则隐藏或审计，无填充旧内容。
- 对比验证：其他来源的候选、其他来源事件、设置与监控开关均保持一致。未发送邮件。服务检查结束时 3 条监控均暂停，恢复后回查随定时检查执行。
- 真实报告：`reports/twitter-thresholds-integration.json`。本轮只回查首批 50 条，剩余在后续检查与现有预算内轮转；未宣称全部历史粉丝指标已补齐。

接口字段和批量上限核对自 [TwitterAPI.io 官方 OpenAPI](https://docs.twitterapi.io/api-reference/openapi.json)：`/twitter/tweets`，最多 50 个 ID；作者字段 `followers`、`isBlueVerified`。网页研究先尝试 agent-reach/Jina Reader，连接失败后读取官方规范；未新增 Key、Cookie 或平台登录。

浏览器验收：默认近 5 天热点显示 1 条待核实结果；页面内容宽度与视口均为 1265px，无水平溢出。截图 `reports/twitter-thresholds-2026-10-16.jpg`。迁移前备份与迁移后数据库再次逐项比对，非 Twitter 候选与非 Twitter 事件保持一致。
